# Playwright (WebKit) для визуальных проверок

Локальный, изолированный набор зависимостей — не часть сайта, не публикуется.
Используется для скриншотов/консоль-проверок на WebKit (iPhone 13, 1440px и т.п.).

Установка (один раз):

```
cd tools/playwright-check
npm install
npx playwright install webkit
```

Запуск сайта для проверки — из корня репозитория:

```
python3 -m http.server 8931
```

Пример проверочного скрипта кладите рядом (например `check.js`) и запускайте
`node check.js` из этой папки — `require('playwright')` резолвится относительно
расположения скрипта.
