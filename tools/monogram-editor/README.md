# Monogram Box Editor — локально

Локальная версия редактора рамок для Verrien, часть II: 155 пластин-указателей
монограмм (`v2-1.jpg` … `v2-155.jpg`, по 15 рамок на каждой — итого 2311 рамок).
Логика и интерфейс — как у старого редактора (тот работал как страница на
claude.ai с базой там же, заголовок «Monogram Box Editor»): фиксированная
сетка из 15 рамок на пластине, можно подвинуть и изменить размер каждую,
«Сбросить к сетке» возвращает исходную раскладку, «Сохранить пластину»
фиксирует текущее положение. Отличие только в хранении — вместо базы на
claude.ai здесь локальный файл на диске, никаких внешних сервисов, работа
не тратит лимиты Claude.

Это отдельный инструмент от `tools/crop-editor/` — тот работает с целыми
сканами книг (поиск гравюр на странице), этот — только с уже опубликованными
пластинами-сетками монограмм Verrien (двигает/подгоняет готовые 15 рамок на
композитном листе).

## Запуск

```
cd ~/Projects/library
python3 tools/monogram-editor/server.py
```

Книга и пластины зашиты в инструмент (это Verrien-only редактор), выбирать
ничего не нужно. В Терминале появится адрес вида `http://127.0.0.1:8812/` —
откроется сам в браузере (порт меняется флагом `--port`; `--no-open`, если
не нужно открывать браузер автоматически). Терминал не закрывайте, пока
работаете.

## Откуда берёт пластины

`~/Projects/library/books/verrien/img/v2-N.jpg` — те же файлы, что уже
опубликованы на сайте (это композитные листы-сетки монограмм, не сырые
сканы). Инструмент их только читает, ничего там не меняет и не пишет.

## Куда сохраняет

`~/Projects/library/books/verrien/_crops/monograms.json` — пишется на диск
**сразу** при нажатии «Сохранить пластину», отдельно для каждой пластины.
Формат:

```json
{
  "v2-1.jpg": {
    "items": [
      {"id": "v2-1-1", "num": "1", "bbox": [12.31, 9.89, 25.3, 15.41]},
      {"id": "v2-1-2", "num": "2", "bbox": [38.02, 9.68, 26.6, 14.9]}
    ],
    "confirmed": true,
    "updatedAt": "2026-10-25T20:43:00.000000Z"
  }
}
```

`items` — 15 рамок пластины в фиксированном порядке (id и номер заданы
изначально, двигать/менять размер можно только `bbox`: `[x%, y%, width%,
height%]` от размера изображения). `confirmed: false` — рамки ещё не
подтверждены в этом редакторе (так стоит у всех после импорта архивной
базы — см. ниже); `confirmed: true` — вы явно нажали «Сохранить пластину»
для этого листа. Счётчик вверху (`N из 155 подтверждено`) считает именно
это, а не то, сколько рамок в принципе на месте.

Файл уже один раз заполнен: все 2311 рамок импортированы из архивной базы
старого редактора (`~/Projects/photos/_archive/verrien_crops_2026-10-25.json`)
в той же системе координат — это стартовая точка, `confirmed: false`
у всех 155 пластин. Повторный импорт этим инструментом не делается — если
файл уже существует, он не перезаписывается при запуске.

## Как пользоваться

**Запуск.** В Терминале:

```
cd ~/Projects/library
python3 tools/monogram-editor/server.py
```

Браузер откроется сам на странице с первой пластиной.

**Работа со страницей.** Сверху — «Пред./След.» для перехода между 155
пластинами, поле «Пластина N →» — чтобы перейти сразу на нужный номер.
На самой пластине уже нарисованы 15 рамок (сетка монограмм):

- тащите рамку целиком за центр — чтобы подвинуть;
- тащите кружок в углу рамки — чтобы изменить размер;
- если накосячили — «Сбросить к сетке» вернёт рамки этой пластины к
  исходной раскладке (не сохранено, пока не нажали «Сохранить пластину»);
- когда рамки на пластине устраивают — «Сохранить пластину»: запишет их
  на диск и пометит пластину подтверждённой (рамки станут зелёными).

Рамка жёлтая/красная — не подтверждена в этом редакторе (так после
импорта, пока вы её не открыли и не сохранили); зелёная — подтверждена.

**Остановка.** Ctrl+C в Терминале, где запущен редактор. Всё, что уже
сохранено кнопкой «Сохранить пластину», лежит на диске — ничего не
потеряется. Следующий запуск — та же команда, продолжаете с того же места.

**Сохранение в git.** Сам редактор ничего не коммитит — это вручную, когда
готовы:

```
cd ~/Projects/library
git add books/verrien/_crops/monograms.json
git commit -m "[verrien] monogram boxes"
git push
```

## Что дальше
