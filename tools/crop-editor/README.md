# Локальный редактор обрезки

Сделан на основе разметки и логики редактора обрезки Cartari (тот работал
как страница на claude.ai с базой там же) — здесь то же самое: рамки,
флажок, навигация, но полностью локально, без внешних баз. Одна страница
скана может содержать несколько гравюр — для каждой рисуется своя рамка.

## Запуск

```
python3 tools/crop-editor/server.py <книга>
```

Например:

```
python3 tools/crop-editor/server.py cartari
python3 tools/crop-editor/server.py iconologie --port 8809
```

`<книга>` — имя папки в `~/Projects/photos/` (cartari, iconologie, grosson,
verrien, alciato, audran — или любая новая, если появится папка с таким же
именем и в `photos/`, и (для сохранения) в `books/` этого репозитория).

Открывает браузер сам на `http://127.0.0.1:8808/` (порт меняется флагом
`--port`; `--no-open`, если не нужно открывать браузер автоматически).

Остановить — Ctrl+C в терминале.

## Откуда берёт фото

Рекурсивно обходит `~/Projects/photos/<книга>/` и берёт все `.jpg`/`.jpeg`/
`.png` (у grosson это `raw/` + `raw_extracted/`, у alciato — `pages/`, у
остальных — файлы прямо в папке книги). Ничего не копирует и не меняет на
диске в этой папке. Не-картиночные файлы (например служебный `_index.json`
у cartari/verrien — это индекс сканов Гейдельбергской библиотеки, не
гравюра) пропускаются молча при старте, но выводятся в консоль списком —
если число найденных фото меньше числа файлов в папке, это первое, что
стоит проверить.

## Куда сохраняет

`~/Projects/library/books/<книга>/_crops/crops.json` — пишется на диск
**сразу** при каждом действии (не нужно отдельно нажимать что-то вроде
«Сохранить всё»). Формат:

```json
{
  "0051_10.jpg": {
    "boxes": [
      {"x": 12.5, "y": 11.0, "w": 72.0, "h": 74.0, "label": "Diana"},
      {"x": 10.0, "y": 60.0, "w": 30.0, "h": 20.0, "label": ""}
    ],
    "noPlate": false,
    "flagged": false,
    "updatedAt": "2026-10-26T00:27:08.402325Z"
  },
  "0052_11.jpg": {
    "boxes": [],
    "noPlate": true,
    "flagged": false,
    "updatedAt": "..."
  }
}
```

`boxes` — список рамок в порядке отображения (его можно менять вручную
стрелками ▲▼ прямо на странице); у каждой рамки `x/y/w/h` — проценты от
размера изображения, и `label` — подпись, которую вы вводите сами (номер
или короткое обозначение вроде «1», «a», «Diana», «fig.3»); подпись видна
прямо на рамке на странице и попадает в экспорт описи. Если подпись не
ввели, на рамке и в экспорте используется порядковый номер (1, 2, 3…) —
это просто подсказка по умолчанию, не отдельное значение, которое нужно
сохранять. Пустой список + `noPlate: true` — страница просмотрена, гравюр
на ней нет (кнопка «Нет гравюры»); `flagged: true` — отмечено «что-то не
так», можно ставить вместе с рамками или отдельно.

Старые рамки из прошлой (claude.ai) базы редактора **не импортируются** —
каждая книга в этом инструменте начинает с чистого листа. Архив прежней
базы Cartari — в `~/Projects/photos/_archive/cartari_crops_*.json` (не
читается этим инструментом).

## Несколько гравюр на одной странице

Кнопка «+ Рамка» добавляет ещё одну рамку поверх текущей страницы. У каждой
рамки: поле подписи (вводится прямо на рамке), крестик для удаления именно
её, и — если рамок на странице больше одной — стрелки ▲▼ в углу, чтобы
поменять порядок рамок вручную. «Сбросить рамки» убирает все рамки текущей
страницы (не сохранено, пока не нажата «Сохранить»).

## Счётчик

В шапке — пять чисел, посчитанные прямо из `crops.json`: всего страниц /
с гравюрами (число рамок, и отдельно — на скольких страницах) / без гравюр
/ флажки / не просмотрено. Пересчитывается при каждом сохранении.

## Экспорт описи

Кнопка «Экспорт описи» пишет `~/Projects/library/books/<книга>/_crops/inventory.csv`
(столбцы: страница, подпись, координаты, флажок) — по одной строке на
**каждую рамку** (не на страницу), в том порядке, в котором рамки стоят на
странице. Страницы без рамок (в том числе «нет гравюры» и не просмотренные)
в опись не попадают — она про сами гравюры, не про страницы. Можно жать
в любой момент, перезаписывает файл заново из текущего `crops.json`.

## Важно

Инструмент не требует внешних пакетов (`http.server`/`csv` из стандартной
библиотеки Python 3) — только `python3` в системе. `books/*/_crops/` не
добавлена в `.gitignore` — попадёт в git как обычно.

## Как пользоваться

**Запуск.** Открываете терминал, переходите в папку `library` и запускаете:

```
python3 tools/crop-editor/server.py cartari
```

(вместо `cartari` — имя нужной книги). В браузере сам откроется страница
редактора — ничего дополнительно открывать не нужно.

**Работа со страницей.** Сверху — название книги и кнопки «Пред./След.» для
перехода между страницами скана, поле «имя файла…» — чтобы сразу перейти
на нужную страницу по части имени файла. На самой странице:

- рисуете рамку кнопкой «+ Рамка», тащите её мышью целиком или за уголок,
  чтобы поменять размер;
- вписываете подпись прямо в поле на рамке (номер, буква, короткое слово —
  как удобно; если ничего не ввести, останется номер по порядку);
- если рамок несколько — стрелками ▲▼ в углу рамки меняете их порядок;
- крестиком у рамки удаляете именно её, кнопкой «Сбросить рамки» —
  все рамки сразу (если ещё не нажали «Сохранить»);
- если на странице гравюр нет — жмёте «Нет гравюры», она пропускает
  текущую страницу и переходит к следующей;
- если со страницей что-то не так (плохой скан, непонятно, что за гравюра
  и т.п.) — ставите галочку «Что-то не так с этим листом»;
- в конце — кнопка «Сохранить»: записывает текущую страницу на диск и
  переходит к следующей.

**Остановка.** Просто нажимаете Ctrl+C в терминале, где запущен редактор.
Всё, что уже было сохранено кнопкой «Сохранить» или «Нет гравюры», уже
лежит в файле на диске — ничего не потеряется. Запустить снова — та же
команда, редактор откроется с того места, где `crops.json` оставил данные.

**Сохранение в git.** Сам редактор ничего в git не коммитит — это делаете
вы сами, когда готовы. Из папки `library`:

```
git add books/<книга>/_crops
git commit -m "<книга>: разметка обрезки"
```

Опись (`inventory.csv`) обновляется кнопкой «Экспорт описи» в редакторе —
после неё тоже можно добавить файл в тот же коммит (`git add` той же
командой подхватит и `inventory.csv`, он лежит в той же папке `_crops/`).
