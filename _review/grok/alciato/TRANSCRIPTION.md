# Инструкция: транскрипция Alciato, *Emblemata*, Lyon 1551

Версия 0.2 (2 ноября 2026): уточнена по итогам пилота (`pilot/`). Документ самодостаточен: исполнителю не нужно ничего, кроме этого файла и папки `scan/`.

## 1. Цель и объём

Транскрибировать **всю книгу 1551 г. заново по скану** `scan/frame_NNNN.jpg` (экземпляр Getty Research Institute, Internet Archive `emblemata00alci_0`).

- Соответствие кадров и страниц: **страница N = кадр N + 6**. Титул — кадр 0007 = с. [1]; кадр 0006 — чистый форзац.
- В объём входят:
  - титул (0007);
  - привилегия на французском (0008);
  - Ad lectorem (0009–0011);
  - посвящение Пейтингеру (0012);
  - 3 посвятительные эмблемы (0013–0015);
  - все эмблемы (0016–0232, включая текстовые продолжения);
  - Index emblematum (0233–0237);
  - колофон (0237).
- Кадры 0001–0006 и 0238–0244 (переплёт, форзацы, пустая страница) получают запись с `page_type: "blank"` и коротким описанием в `notes`. Карандашные пометы владельцев не транскрибируются, только упоминаются.
- **`entries.json` не основа и не источник.** Исполнители его не открывают. Сверка с ним — отдельная задача после завершения транскрипции.
- Перевод в объём не входит.

## 2. Папки

```
_review/grok/alciato/
  TRANSCRIPTION.md          эта инструкция
  scan/                     кадры (только чтение)
  runs/t1/ … runs/t4/       четыре независимых прогона, frame_NNNN.json
  merged/                   итог главного агента, frame_NNNN.json
  discrepancies.md          все расхождения + список для пользователя
  discrepancies.json        то же машинно
  pilot/                    пилот (8 кадров), не трогать
```

## 3. Порядок работы

1. **Четыре слепых прогона.** t1–t4 делают **разные субагенты**. Каждому дают только эту инструкцию и список кадров. Субагенты не видят чужих прогонов, `merged/` и `entries.json`.
   - Рекомендуемое распределение:
     - t1 — по полному кадру;
     - t2 — по полосам полного разрешения;
     - t3 — по контрастированному изображению;
     - t4 — OCR (Tesseract 5, `lat+grc`, для 0008 `fra`) с ручной разметкой схемы поверх сырого текста.
   - Сырой вывод OCR сохраняется рядом (`frame_NNNN.ocr.txt`).
   - OCR по пилоту — голос только по составу слов и строк, **не по диакритике и не по ſ/f** (теряет тильды, путает ſ/f, b/h).
2. **Сравнение.** Главный агент сравнивает прогоны по каждому полю дипломатического слоя.
   - Несущественно: ширина пробелов вокруг знаков препинания (в печати они узкие, «Syre,de»). Сравнивать после схлопывания пробелов.
3. **Решение по зуму.** Каждое расхождение главный агент решает только по **увеличенному фрагменту скана** (×2–×3).
   - Разрешено привлекать другие страницы этой же книги: тот же глиф в другом месте, текст эмблемы для строки указателя, коллацию для сигнатур.
   - Каждое решение записывается в `discrepancies.md`: ID, кадр, место, варианты t1–t4, итог, тип, как решено.
4. **Нерешённое — пользователю.** Нерешённое по скану не угадывается: в `merged` ставится `[?]` или `[...]`, а пункт уходит в раздел «Список для пользователя» в `discrepancies.md`.
   - Туда же идут сомнения в самом печатном тексте, даже при согласии всех прогонов (пример — U1 пилота: «co conſiderantium»).
5. Работать порциями (например, по 20 кадров): прогоны → сравнение → отчёт.

## 4. Дипломатический слой (`diplomatic`)

Точно как напечатано, построчно (массив строк = строки печати).

- **ſ** — длинное s, **s** — круглое. Различать всегда (в пилоте «hisq;» — круглое).
- Лигатура **ß** (ſs) → `ſs`; два длинных подряд → `ſſ` (пример: «geſsiſſe»).
- Лигатуры **æ œ** и **&** — как есть. Курсивное «e caudata» **ę** — как есть (`quę`).
- Лигатуры **ct, st, ff** и т. п. **не отмечаются**: печатаются буквами.
- **q** с крючком/надстрочным знаком (que) → `q;` (один знак, следующую запятую не добавлять). Пример: `quoq;`, `teneraq;`.
- **Тильда/макрон** над гласной → гласная с тильдой в Unicode: `ã ẽ ĩ õ ũ` (`dõner`, `nũquã`, `pẽdula`).
- Акценты печати (à, quòd, penè, cùm, quî, ferè) — как напечатано.
- **u/v, i/j** — как напечатано (`uidit`, `Iouis`, `Dij`).
- Регистр как в печати; капители записываются заглавными. Разрядку не передаём.
- **Переносы**: дефис в конце строки сохраняется; двойной дефис печати → `=` (`Maximilia=`). Перенос без знака сохраняется как разрыв строки (`imagini` / `bus`).
- **Пунктуация** — как напечатано, включая строчную после точки («Qui cupit.hoc»).
- **Греческий** — как напечатано, в Unicode, с диакритикой, если она читается.
  - Лигатура καί → `ϗ`, лигатура ου → `ȣ`.
  - Сомнительная буква или знак → `[?]` сразу после слова или буквы.
- **Буквица** (гравированная) — вносится в текст первой буквой; в блоке — поле `"initial": "I"`.
- **Опечатки** не исправляются (`argmmentum`, `PRVDBNTIA.`).
- **Срезанное корешком/обрезом** → `[...]`, видимые буквы сохраняются (`PRIVILE[...]`).
- **Неуверенно** → `[?]` после слова или буквы (`plurimum[?]`). **Нечитаемо** → `[...]`. Ничего не угадывать и не достраивать молча (в пилоте t1 достроил «PRIVILEG[IO]» — это ошибка).
- **Курсивная L** этого шрифта похожа на «I.» (ALCIATI, LOCOS, EMBL.) — проверять по контексту и по тому же глифу на других страницах.
- **Повреждённая литера** (e выглядит как c) — читать по форме и контексту, отметить в `notes`.

## 5. Слой чтения (`reading`)

Нормализованный текст для чтения и последующего перевода.

- ſ → s; ſs / ſſ → ss.
- Тильда/макрон раскрываются в n/m по позиции (`dõner` → donner, `quẽquam` → quenquam, `Obdurãdũ` → Obdurandum). Написание не «классицизируется».
- `q;` → que.
- Сокращения с точкой (`illuſt.`, `Maximil.`, `LVGD.`, `&c.`) **не раскрываются**: оставляются как напечатано.
- **u/v** нормализуются по значению: u — гласная, v — согласная (`Iouis` → Iovis, `vt` → ut, `Vltrà` → Ultrà). В латыни **j → i** (`Dij` → Dii, `gentilitijs` → gentilitiis). Во французском i/j не нормализуются (`adiouster`, `Iaulne`), а u/v нормализуются.
- **Лигатуры: сохраняем.** æ, œ, & остаются; ę → æ. В греческом ϗ → καὶ, ȣ → ου.
- Акценты печати сохраняются.
- **Переносы**:
  - в прозе строки склеиваются в один абзац, переносы снимаются;
  - в стихах строка печати = строка стиха;
  - в девизах строки склеиваются.
- **Пунктуация**: печатная, но после , : ; ? ! ставится пробел.
- **Опечатки**: в слое чтения исправляются только **очевидные**, и каждая исправленная записывается в `errata` (см. §6). Сомнительные не исправляются: остаются как есть с `[?]` и идут пользователю. *(Политика ждёт подтверждения пользователя — U5 пилота.)*
- Французская орфография XVI в. не модернизируется.
- Греческий: без нормализации, кроме раскрытия лигатур. Словораздел, если его нет в печати (`ΓΑΝΝΥΣΘΑΙΜΗΔΕΣΙ,`), не вносится; толкование — в `notes`.

## 6. Схема JSON (одна страница = один файл `frame_NNNN.json`)

```json
{
  "schema": "alciato-1551-page/0.1",
  "frame": 37,
  "source": "scan/frame_0037.jpg",
  "page": "31",
  "signature": null,
  "catchword": null,
  "page_type": "emblem",
  "running_head": "PRVDENTIA.",
  "rubric": null,
  "emblems": [
    {
      "motto": {"diplomatic": ["In ſtatuam Bacchi."], "reading": "In statuam Bacchi."},
      "subheading": {"diplomatic": "DIALOGISMVS.", "reading": "DIALOGISMUS."},
      "engraving": {
        "position": "между девизом и эпиграммой",
        "description": "описание сюжета по-русски",
        "inscriptions": [{"where": "…", "text": "дословно, как напечатано"}]
      },
      "epigram": {"diplomatic": ["строка", "…"], "reading": ["строка", "…"]},
      "continues_on_next_page": true,
      "notes": "…"
    }
  ],
  "ornaments": [],
  "errata": [
    {"printed": "…", "corrected": "…", "certainty": "очевидная|вероятная|сомнительная",
     "applied_in_reading": true, "comment": "…"}
  ],
  "notes": "…"
}
```

Поля:

- `page` — печатный номер страницы. Если номер не напечатан, ставится выведенный в квадратных скобках (`"[3]"`).
- `signature` — сигнатура, если она напечатана (`"A 2"`); иначе `null`.
- `catchword` — кустода; иначе `null`. Сигнатура и кустода хранятся **отдельно** от текста.
- `page_type` — одно из: `title`, `front_matter`, `emblem`, `emblem_continuation`, `index`, `colophon`, `blank`. Страница указателя с колофоном (0237) получает `index`, а колофон записывается отдельным блоком `{"kind": "colophon"}`.
- `running_head` — колонтитул над рамкой: печатное имя локуса, как напечатано, вместе с опечатками.
- `rubric` — заголовок внутри полосы (AD LECTOREM., PRIVILEGE DV ROY., шапка указателя). Это не колонтитул.
- `emblems[]` — эмблемы страницы, по порядку (в этой книге одна на страницу).
  - `motto` — девиз.
  - `subheading` — необязательно: подзаголовок вида DIALOGISMVS.
  - `engraving` — `position`, `description` (по-русски: что изображено, без толкований), `inscriptions` (дословно, включая греческий).
  - `epigram` — оба слоя.
  - `continues_on_next_page` — продолжается ли текст на следующей странице.
- **`emblem_continuation`**: `motto` и `engraving` = `null`. Добавляется `continuation_of: {frame, page, motto}`. Текст — в `epigram`, строки нумеруются заново для этой страницы.
- Нетиповые страницы (титул, привилегия, предисловие, посвящение) пишут текст в `blocks[]`: `{kind, lang, initial?, diplomatic[], reading[], notes}`. `kind` — `title_text`, `imprint`, `privilege_line`, `prose`, `verse`, `colophon`.
- **Указатель**:
  - `columns[]` — построчно в дипломатическом слое: `left` / `right`;
  - `entries[]` — `{locus, motto_diplomatic, motto_reading, page_ref, notes?}`;
  - `page_ref` — строка, как напечатано. Если номер не напечатан — `null` и заметка (ничего не вписывать).
- `ornaments[]` — несюжетные заставки и орнаменты в полосе (пример — 0038): `position`, `description`.
- `errata[]` — найденные опечатки печати.
- `notes` — всё прочее: курсив, отступы, повреждения.
- **Не вводить** поля типа рамки полосы и координаты/границы кропов (решение пользователя). Орнаментальная рамка полосы не описывается. Исключение — титул: там рамка и есть гравюра.
- Главный агент добавляет в `merged/` поле `discrepancy_ids`.

## 7. Неуверенность — коротко

`[?]` — читаю, но не уверен. `[...]` — не читается или срезано. Каждый `[?]` и `[...]` в `merged/` должен иметь строку в `discrepancies.md` (решение или вопрос пользователю). Ничего не придумывать.

## 8. Отчёт после каждой порции

- Сколько кадров сделано.
- Число расхождений: по типам; решено или для пользователя.
- Список для пользователя.
- Найденные опечатки (errata).
- Предложения по правке инструкции.
