## Структура

- `runs/t1/` — чтение по уменьшенному кадру (~1000 px по ширине), без зума.
- `runs/t2/` — чтение по полосам полного разрешения (~2175 px).
- `runs/t3/` — прицельные зумы ×2–×3 спорных мест и сверка с другими страницами книги (не с `entries.json`).
- `runs/t4/` — сырой вывод Tesseract 5 (`-l lat+grc --psm 4`; для 0008 `-l fra`), без правки. `.txt`, не JSON.
- `merged/frame_NNNN.json` — итог по схеме из `TRANSCRIPTION.md` (`schema: alciato-1551-page/0.1`).
- `discrepancies.md` / `discrepancies.json` — все расхождения; спорное и вопросы вынесены в `../OPEN_QUESTIONS.md` (v0.3).

## Ограничения пилота

1. **t1–t3 не независимы.** Их делал один агент последовательно, и он видел свои прежние чтения. В основной работе нужны 4 отдельных субагента, которые не видят друг друга (см. `TRANSCRIPTION.md`, §3). Пилот проверял формат, схему и типы ошибок, а не независимость.
2. **Файлы `runs/t1–t3` восстановлены из рабочих заметок.** Это итоговый текст, в который обратно подставлены зафиксированные варианты прогонов (в каждом файле стоит поле `reconstructed_from_notes: true`). Подстановка механическая, поэтому вариант иногда попадает и в слой чтения или в заметки.
3. **t4 (OCR) — единственный по-настоящему независимый прогон.** Его вклад: подтвердил «co conſiderantium» (U1) и «puerili» (0016), не пропустил ни одной строки, а по диакритике бесполезен.
4. `entries.json` в пилоте не открывался.
