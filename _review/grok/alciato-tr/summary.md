# «Эмблемы» Альчато (Lyon 1551): новый перевод RU / EN / FR

## Что сделано
- Переведены все 208 эмблем из `books/alciato/entries.json` (main@1f4049a), на три языка: `ru.json`, `en.json`, `fr.json` (по 208 ключей, 1–208).
- Источник латыни: `books/alciato/_text/TEXT_reading.md` (main@1f4049a), при сомнениях — `pages/NNNN.md`. Каждый язык переведён прямо с латыни (не с русского). Старые `_translation/*.json` и `emblems.json` источником не служили; `ru.json` из grok-review использован только как образец формата.
- Правила и имена: `_translation/RULES.md` и `GLOSSARY.tsv` из ветки grok-review (по указанию; на main этого каталога нет).
- Формат: ключ = номер эмблемы; поля `motto`, `subheading`, `epigrams[{label, reading[]}]`, `greek[{where, original, translation}]`. Число строк в каждом `reading[]` равно числу строк латыни (проверено скриптом для всех 208 × 3).
- Перевод построчный, смысловой, без рифмы и украшений; пояснения в [квадратных скобках] — только там, где без них непонятно; игра слов — в круглых скобках с латинским/греческим словом (RULES 7).
- Греческие девизы, подзаголовки и строки переведены: в `motto`/`subheading` оригинал в печатной форме + перевод в скобках, плюс запись в `greek[]` (эмблемы 1 [надпись гравюры], 13, 14, 31, 66, 71, 106, 107, 118, 134, 162, 164, 184, 203). Латинские надписи гравюр не переводились (по RULES).
- Второй эпиграф под рубрикой ALIVD выделен как отдельный элемент `epigrams` с меткой «Другое.» / "Another." / "Autre.".
- Французская типографика: неразрывный пробел перед ; : ! ? » и после «.

- **208 против 211.** В `entries.json` (main) 208 эмблем (стр. 10–226); три посвятительные эмблемы (раздел «EMBLEM. DEDIC», стр. 7–9) в 208 не входят и **не переведены**. Старый перевод в grok-review имел 211 номеров, поэтому номера сдвинуты: старый N = новый N−3.

- **Глоссарий:** комментарии с номерами эмблем в `GLOSSARY.tsv` даны по старой нумерации (сдвиг на 3).
- **Эмблемы без печатного девиза:** 44, 68, 87, 93, 173 — `motto: null` (над гравюрой только рубрика).
