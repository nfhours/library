**Репозиторий**: `https://github.com/nfhours/library.git` [проверено: `git remote -v`].

**Как библиотека подключена к личному сайту владельца** [со слов пользователя, уточнение после составления первой версии этого файла]: встраивания (iframe/скрипт на стороннем сайте) **нет**. ### `book.json` — поля, встречающиеся хотя бы в одной из трёх книг [проверено: `python3 -c "print(d.keys())"` по каждому файлу]

### Маршруты [проверено: чтение `app.js`, функции `parseHash`/`route`, строки ~305-347]

- `#/<slug>/<id>` — карточка статьи
- `#/<slug>` — указатель книги
- `#/<slug>/about` — страница «О книге»
- `#/<slug>/plate/<n>` — просмотр таблички целиком с номерами (только для книг с `viewer:"plate"`)
- `#/` или пусто — список всех книг, если блок не закреплён на одну книгу через `data-book`
- Старый формат без слага `#/p1-3` по-прежнему работает и ведёт в `iconologie` (специальная ветка в `parseHash`, regex `/^p[12]-\d+$/`) — это для обратной совместимости со ссылками, сохранёнными до появления библиотеки.

`data-book="<slug>"` на `div#iconologie` запирает блок на одну книгу; `data-book="library"` — специальное значение, явно включает список всех книг (так подключён `index.html`); без атрибута — поведение по умолчанию, показывает `iconologie` напрямую [проверено: чтение кода, строки 15-21 app.js]. `data-lang` — язык (`ru`/`en`/`fr`), приоритет `?lang=` в URL > сохранённый выбор (localStorage) > `data-lang` на блоке > `ru` [проверено: строки 146-157]. `data-top` читается через `root.dataset.top` и выставляет CSS-переменную `--top` (строка 12 app.js) — это реальный код, но для чего он в продакшене используется (под какую шапку сайта подгоняется отступ) — неизвестно, т.к. неизвестно, где и как блок встроен на личном сайте.

**Как устроены данные редактора**: страница встраивает в себя JSON `window.__CARTARI_DATA__` = `{blobMap, fileOrder, pages, titles}`, где `blobMap` — соответствие `"cartm1.jpg" → <id блоба с картинкой>`, `fileOrder` — порядок показа, `pages`/`titles` — для отображения номера страницы и названия. Сами изображения — это полные нераскадрированные сканы raw2 (не кропнутые), загруженные как assets артефакта.

**База данных редактора** (через Artifact-возможность `db`, коллекция `crops`, один документ на файл):
```json
{"id": "cartm1.jpg", "data": {"box": [x%, y%, w%, h%], "flagged": bool}, "version": N, "updatedAt": "..."}
```
- **«Рамка»** = пользователь реально подвинул/подогнал прямоугольник — на практике отличается от значения по умолчанию `[8, 8, 84, 84]`.
- **«Флажок»** = `flagged: true` и рамка равна дефолту `[8,8,84,84]` — то есть пользователь нажал «Что-то не так», но саму рамку не трогал. Это НЕ синоним готовой обрезки.
- Значение по умолчанию `[8,8,84,84]` жёстко прошито в функции `defaultBoxFor()` внутри HTML редактора — именно по совпадению с этим значением в этой сессии отличали «реальную рамку» от «просто флажка» [проверено: сравнение каждой записи в БД с этим литералом].

## 9. Cartari: русский перевод (добавлено 2026-10-29)

Отдельная линия работы, не связанная с разметкой гравюр из раздела 4. Всё лежит в `books/cartari/_translation/`.

### Файлы
- `RULES.md` — 10 правил перевода (источник `TEXT_reading.md`; цитаты блоком `>`; пометы на полях строкой `<aside>` перед абзацем; абзацы только в конце фразы; подписи гравюр после абзаца; неточности и этимологии автора переводятся как напечатано; сомнительное место — `[?]`). Читать целиком перед началом новой главы.
- `GLOSSARY.tsv` — общий глоссарий имён и терминов (145 строк с заголовком, колонки italian / russian / english / french / comment). Новые термины каждой главы добавляются сюда, а не изобретаются заново.
- `ru/diana.md` — готовый перевод главы о Диане.
- `ru/diana.review.md` — отчёт проверки этой главы.

### Состояние
- **Глава о Диане, сканы 0129–0154** (печатные с. 97–112): переведена целиком на Sonnet, проверена на Opus. Проверка нашла 39 находок (3 ошибки смысла, 20 неточностей, 16 замечаний по стилю), все исправлены; у каждой находки в `diana.review.md` есть строка «Статус». Объём перевода около 7080 слов (без пометок на полях). Коммиты: перевод `342cbb6e`, проверка `4db216b1`, исправления `4be5c431` [проверено: `git log -- books/cartari/_translation`].
- **Следующая глава — GIOVE**, начинается со скана **0155** (на скане печатная страница 113, колонтитул «De gli Antichi»). Где она кончается — не определено; границу нужно найти по `books/cartari/_text/pages/`, как это делалось для Дианы (глава обрывается там, где на следующем скане стоит заголовок новой главы).

### Решение о порядке работы
Дальше переводим на **Sonnet**, и **каждую главу проверяет Opus** отдельным проходом: сверка с итальянскими сканами, список находок в `ru/<глава>.review.md` (цитата перевода, оригинал, что не так, правка, серьёзность; итоговые числа), затем исправления с отметкой статуса у каждой находки.

### Что стоит учесть по опыту Дианы
- В первом проходе Sonnet чаще всего ошибался в: глаголах и местоимениях в цитатах (Клавдиан: «его»/«своих»), идиомах (`cacciare un cavallo`), согласовании в длинных периодах, расходящихся формах имён между частями главы (Свида/Суда), потерянных пометах на полях. Проверку стоит нацеливать именно на это.
- Перед переводом новой главы сверить термины с глоссарием; в Диане в глоссарии не хватало около 15 постоянных слов (Кимвал, Гриф, Лунницы и т. д.), они добавлены.
- Файл `tools/match_articles.py` в репозитории не отслеживается и не коммитится, пока пользователь не скажет иначе.
