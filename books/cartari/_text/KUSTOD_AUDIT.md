# Аудит «кустод попал в тело страницы» (04.11.2026)

Проверялись страницы, где последнее слово тела `pages/NNNN.md` совпадало с кустодом и с первым словом следующей страницы (то есть слово стояло в транскрипции дважды подряд на стыке страниц). Поиск: скрипт по `pages/*.md` (нормализация как в `tools/check.py`), затем `tools/check.py` нашёл ещё одну страницу, 0162, которую первый скрипт пропустил из-за пунктуации (`tema?*`). Всего 21 кандидат.

Метод: для каждой страницы две вырезки ОРИГИНАЛЬНОГО фото (скан S = файл с префиксом S−1): нижние 32% страницы S и верхние 32% страницы S+1. Читал независимый субагент без исправлений в тексте, вердикт по тому, на каком слове кончается последняя печатная строка и стоит ли кустод отдельной строкой под текстом.

Вердикты: **а** — слово-кустод ошибочно попало в тело, снято; **б** — в книге настоящий повтор слова, ничего не менялось.
