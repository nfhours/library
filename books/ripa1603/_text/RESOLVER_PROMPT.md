# Задание разбирающему субагенту (одна страница, Ripa 1603)

1. Прочти `~/Projects/library/books/ripa1603/_text/ALGORITHM.md` целиком.
2. Картинка страницы: `_text/_img/NNNN.jpg` (NNNN — в задании). Вырезки по расхождениям: `_text/_work/NNNN/crops/NNNN_<id>.jpg` (по одной на расхождение тела). Список расхождений: `_text/_work/NNNN/diffs.json` (id, variants = три варианта read1/read2/read3, majority = индекс варианта большинства или null, ctx). Расхождения с `kind` field/marg/multi (поля, маргиналии) — решай по общему виду `_img` (маргиналии/поля читай на нём; при необходимости увеличь нужный участок через Python PIL в /tmp — не в репозиторий).
3. Не открывай `_reads/` и `pages/` — тексты уже в diffs.json; ты решаешь по картинке.
4. По каждому `id` реши, кто прав, и запиши строку в `_text/_work/NNNN/answers.txt` ровно в формате (разделитель полей « ; »):
   ```
   N PAGES ; wrong=              (верен вариант большинства; ошибки нет — шум формата → пустой wrong)
   N READ2 ; wrong=1,3 ; hidden=text   (верен read2; ошибались read1 и read3; hidden — если два прочтения совпали на неверном: text|latin|margin)
   N ERRATA:напечатано|исправление ; wrong=
   N FIX:точный верный текст ; wrong=1,2,3     (верного нет ни у одного)
   N UNSURE ; wrong=             (неразличимо → в тексте [?])
   N RECROP                      (вырезка промахнулась; пиши только если иначе нельзя)
   ```
   `wrong=` — перечисли номера прочтений, чей вариант НЕВЕРЕН по картинке (у варианта большинства — тоже, если он неверен). Диакритика/регистр/апострофы и u/v/i/j — как напечатано. Опечатки печатника — только `ERRATA:`, если по вырезке однозначно (форма и то, что это опечатка); иначе пиши как напечатано (PAGES/READn).
5. Затем просмотри всю страницу по `_img/NNNN.jpg` на скрытые совпавшие ошибки (все три прочтения одинаково неверны, а в список не попали): диакритика/ударения, регистр, лигатуры, пропущенные слова, цифры, латинские цитаты. Найденное — строкой `NEW text|latin|margin ; было → стало` (`было` — точная уникальная подстрока текущего черновика `_text/pages/NNNN.md`, который ты МОЖЕШЬ прочитать для этой цели; `стало` — верный текст). Не правь ничего, в чём не уверен. Этот шаг ОБЯЗАТЕЛЕН для каждой страницы (даже если расхождений 0): в ответе напиши «страница просмотрена целиком».
6. Ответ — только: «answers.txt записан, расхождений N, NEW M, страница просмотрена целиком». Без пересказа текста страницы.

7. ВАЖНО: строка NEW работает ТОЛЬКО по телу страницы. Исправления в строках `Колонтитул:`, `Кустод:`, `Сигнатура:`, `Маргиналии:` (например, печатный номер 171 → 271, пропущенная маргиналия) в NEW НЕ пиши (reconcile упадёт). Пиши их в отдельный файл `_text/_work/NNNN/footer_fixes.txt`, по одной строке: `было → стало` (для маргиналии: `Маргиналии: → Маргиналии: текст`), и упомяни в ответе.
