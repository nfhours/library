# Ripa 1603: точная текстовая копия книги

Задача: получить полный текст книги «Iconologia, overo Descrittione di diverse imagini cavate dall'antichità, & di propria inventione» (Cesare Ripa, Roma, Lepido Facii [Lepido Facij], 1603) буква в букву, со всеми гравюрами. Это источник истины для перевода и привязки гравюр к статьям. Технология — картариевская, сразу в итоговой строгой версии: **для ВСЕХ страниц три независимых слепых прочтения + сведение скриптом + вырезки по каждому расхождению + разбор одним субагентом на страницу**. Промежуточные методы Картари (одно прочтение, двойное чтение) не применяются.

## Файлы

Папка `~/Projects/library/books/ripa1603/_text/`:

- `PAGES.tsv` — список 557 сканов по `pagemap.json` (репозиторий ripa-1603): скан, метка, печатная страница, тип, лист IA, адрес картинки.
- `status.csv` — состояние и метрики страниц (собирает `tools/check.py`).
- `TEXT_diplomatic.md` / `TEXT_reading.md` / `ERRATA.md` / `ENGRAVINGS.md` / `PROVENANCE.md` — собирает `tools/build.py` (дипломатический текст «как напечатано», читательский с исправленными опечатками печатника, список опечаток, реестр гравюр/виньеток/инициалов, рукописные пометки и штампы).
- `PROGRESS.md` — состояние, метрики партий, проблемы. `ARTICLES_ON_PAGES.md` — привязка гравюр к статьям (после каждой партии).

## Нумерация: главное правило

Раздел называется по **номеру скана** (порядок листов), печатный номер пишется рядом: `## Скан 0050 · с. 25`. В книге есть сбои печати (109a/109b = «102?/103?», 110 напечатано «112», скачок 111→118 без пропуска текста; опечатки 165→166, 198→189, 462→262 — см. `pagemap.json`, `_docs/ripa1603-stage1.md`). В странице записывать печатный номер **как напечатано** (в `Колонтитул:`); расхождение с `pagemap.json` — строкой `Нумерация: на странице напечатано X, в pagemap Y`. Непрерывность текста проверять по кустодам и смыслу. Уточнение 23 неуверенных печатных номеров делается по ходу чтения (отмечать в PROGRESS.md и в `Нумерация:`).

## Правила транскрипции

1. **Текст** — только напечатанное на странице, как есть:
   - орфография 1603 г. (u/v, i/j, `&`, `ſ`→`s`, ударения и апострофы как напечатано: `è`, `à`, `á`, `ò`…); носовые тильды и сокращения (ã ẽ õ ũ, `cō`, `Cū`) — **как напечатано, не раскрывать** (решение пилота: расхождения читающих по тильдам разбирает разбирающий по вырезке); «-que» → `q;` (как у Картари: `atq;`);
   - пунктуация как в книге; перенос слова на конце строки склеивать в одно слово;
   - стихи, списки, каталоги и указатели — каждая строка/пункт с новой строки; скобка `}` с общей подписью справа — подпись одной строкой после последнего пункта группы;
   - **заголовок статьи** (напр. «ARDIRE MAGNANIMO, E GENEROSO.») — строкой `[ЗАГОЛОВОК: как напечатано, с сохранением регистра]` в том месте, где стоит в тексте; это нужно для привязки гравюр к статьям;
   - **курсив** `*…*` — только как выделение внутри прямого текста (цитата, слово, стих среди прямого шрифта). Целиком курсивные страницы/разделы звёздочками не размечаются;
   - **опечатки печатника** — см. формат `{как напечатано|исправление}` ниже; без однозначности — как напечатано.
2. **Кустод** (слово внизу страницы) — не в тело, а строкой `Кустод: …`; в списках с номерами — целиком. Если на листе нет — пусто, не выдумывать.
3. **Колонтитул** (верх: `DI CESARE RIPA.` / `ICONOLOGIA` + номер) — строкой `Колонтитул: …`.
4. **Сигнатура** (`A`, `A2`, `Bb3`…) — строкой `Сигнатура: …`; нет — пусто.
5. **Маргиналии** — в конце: `Маргиналии:` и пункты `- …`.
6. **Гравюры**: `[ГРАВЮРА: подпись буква в букву]` **одной строкой** (если подписи нет — `[ГРАВЮРА: без подписи]`); виньетки/заставки `[ВИНЬЕТКА: короткое описание]`; буквицы `[ИНИЦИАЛ: X]` (буква входит в первое слово; регистр после буквицы — как напечатано).
7. **Неразборчиво** — `[?]` на месте; не угадывать; строка в PROGRESS.md.
8. **Пустая страница** — только `[ПУСТАЯ СТРАНИЦА]`; никаких описаний бумаги/переплёта.
9. **Рукописные пометки, штампы, владельческие записи** — не текст книги: отдельными строками `Рукописно: …` / `Штамп: …` (сомнительное — `[?]`, один раунд разбора).
10. **Знак без Unicode** — пометой `[знак]` в нужном месте.
11. Порядок строк в конце раздела: `Колонтитул:` → `Кустод:` → `Сигнатура:` → `Маргиналии:` → `Рукописно:`/`Штамп:` → `Нумерация:`.

## Файл страницы `pages/NNNN.md`

Первая строка — служебная шапка (её разбирает `tools/check.py`):

```
<!-- scan: NNNN | label: X | state: todo|draft|done | source: new | method: triple | discrepancies: N | errors_r1: N | errors_r2: N | errors_r3: N | both_wrong: N | noise: N | hidden_errors: N | hidden_errors_latin: X | hidden_errors_margin: Y | hidden_errors_text: Z -->
```

- `discrepancies` — число расхождений между тремя прочтениями (по `compare3.py`; одно расхождение = одно место, где не все три совпали);
- `errors_rK` — в скольких из них прочтение K оказалось неверным по вырезке;
- `both_wrong` — расхождений, где верный вариант не совпал ни с одним из прочтений (FIX) — оценивается по большинству: «два из трёх одинаково неверны» считать как `hidden_errors`, «ни одно не верно» — как `both_wrong`;
- `noise` — расхождения, где по факту ошибки нет (формат);
- `hidden_errors` = `latin + margin + text`: места, где **два из трёх прочтений совпали на неверном** варианте, а третье оказалось право (при обычном двойном чтении они остались бы незамеченными). `_latin` — латинская/греческая цитата, `_margin` — маргиналия/сигнатура/кустод/колонтитул, `_text` — основной итальянский текст. Если не было — нули;
- `state: done` — только после полного процесса ниже.

Считать счётчики **по ходу разбора каждого расхождения** (разбирающий субагент в ответе даёт по каждому номеру, кто прав), не выводить задним числом.

## Опечатки печатника: формат `{как напечатано|исправление}`

Опечатка набора (перевёрнутая/спутанная буква, пропущенная, лишняя, переставленные) переносится как факт издания и сразу даёт исправление: `{segnitauano|seguitauano}`. Порог уверенности: однозначно по вырезке (и форма, и то, что это опечатка); сомнительно — как напечатано без разметки; нечитаемо — `[?]`. НЕ размечать архаичную орфографию (u/v, i/j, `ſ`), непоследовательные ударения, реальные редкие формы. `tools/build.py`: в `TEXT_diplomatic.md` остаётся первое (`a`), в `TEXT_reading.md` — второе (`b`), `ERRATA.md` — список. `tools/check.py` проверяет парность `{ | }`.

## Порядок работы: партия 20 страниц

Основной чат **не открывает картинки и не печатает тексты страниц**: он готовит задания, запускает скрипты, проверяет числа и диффы, коммитит.

1. `python3 tools/prep.py --scans A-B` — `_img/`.
2. **Три независимых слепых прочтения** — три разных субагента (чистый контекст, не видят ни друг друга, ни `pages/`, ни чужих прочтений): каждый читает страницы партии с нуля **только по `_img/NNNN.jpg`** и пишет `_reads/NNNN/read1.md` (read2.md, read3.md). Ответ субагента — только список записанных файлов и страниц со спорными `[?]`; без пересказа содержания.
3. `python3 tools/compare3.py --scans A-B --out _work` — сведение трёх прочтений **без нормализации ударений, апострофов, u/v** (нормализуются только регистр, `ſ`→`s`, пробелы; `i/j` тоже не нормализуется). Выход: `_work/NNNN/diffs.json` (расхождения: номер, три варианта, контекст), служебные поля (`Колонтитул/Кустод/Сигнатура/Маргиналии`) — тоже по трём прочтениям, и черновик `pages/NNNN.md` (`state: draft`) по большинству (при полном трёхстороннем расхождении — по read1).
4. `python3 tools/crop_diff.py --batch-json _work/NNNN/diffs_crop.json --out-dir _work/NNNN/crops` — вырезка по каждому расхождению (по умолчанию полоса 18% высоты, увеличение ×2,5; `RECROP` — повторить с большей полосой).
5. **Разбор — один субагент на страницу** (чистый контекст): получает `ALGORITHM.md` файлом, `_img/NNNN.jpg`, вырезки и список расхождений (с тремя вариантами каждого). По каждому номеру отвечает **одним токеном**:
   ```
   1 PAGES            (верен вариант большинства/черновика)
   2 READ2            (верен вариант read2; READ1/READ3 — аналогично)
   3 ERRATA:printed|corrected
   4 FIX:точный верный текст
   5 UNSURE           (неразличимо → [?])
   6 RECROP
   ```
   Плюс по каждому: `wrong=1,3` (чьи прочтения ошибочны), `hidden=latin|margin|text` — если два прочтения совпали на неверном. Без пояснений. Помимо списка, **проверяет весь текст страницы на скрытые совпавшие ошибки** (диакритика/регистр/лигатуры, где все три совпали и не попали в список) — только по `_img`; найденное сообщает как `NEW:точная замена «было→стало»` и считает в `hidden_errors`.
6. `python3 tools/reconcile.py --scan NNNN --answers _work/NNNN/answers.txt` — применяет решения к черновику, пишет итоговый `pages/NNNN.md` (`state: done`, `method: triple`, все счётчики), правит `status.csv`. Инвариант: `discrepancies = errors_r1+errors_r2+errors_r3 …` не обязателен (считаем по разбору), но `both_wrong`, `noise`, `hidden_errors` записываются обязательно.
7. `python3 tools/check.py` и `python3 tools/build.py` — синтаксис `{ | }`, кустоды (кустод страницы = первое слово следующей по порядку; перед гравюрной страницей — через неё), счётчики. Основной чат сам проверяет диффом `git diff --stat` и выборочно число расхождений из отчёта.
8. **После партии — привязка гравюр к статьям** по `[ЗАГОЛОВОК: …]` на странице и рамкам: обновить `ARTICLES_ON_PAGES.md` и `entries.json` репозитория ripa-1603 (поля `title_printed`, `page`, `img`), расхождения с Tavola — в PROGRESS.md.
9. Коммит после партии, **только явными путями** `books/ripa1603/_text/...` (никогда `git add -A`/`.`): `[ripa1603] text: triple-reading NNNN-MMMM (краткое содержание)`, пуш. После каждых 100 сканов — выборочная сверка 3 случайных страниц с фото основным чатом (читаются только эти 1–3 страницы).

Каждому субагенту передавать `ALGORITHM.md` **файлом целиком** (путь + инструкция прочитать), не пересказом.

## Короткие режимы
- **Страницы-гравюры**: если на листе только гравюра с подписью — одна строка `[ГРАВЮРА: подпись]`, колонтитул, сигнатура. Разбор всё равно по трём прочтениям.
- **Обложки, форзацы, чистые листы**: один взгляд, `[ПУСТАЯ СТРАНИЦА]` или `[ВИНЬЕТКА: …]`/титул как напечатано; `method: single-blank`.
- **Tavola delle Figure (сканы 0017–0025), указатели**: колонки; порядок — по колонкам слева направо сверху вниз; каждая запись — отдельной строкой.

## Запрещено
додумывать текст; менять орфографию; исправлять опечатки печатника вне формата `{|}`; склеивать стихи в прозу; пропускать маргиналии, кустоды, гравюры; писать «проверено» без сверки с изображением; ставить `state: done` без процесса выше; полагаться на OCR; переносить рукописные пометки в тело.

## Метрики Картари для сравнения (основной текст)
~0,15 `both_wrong` на страницу при двойном чтении; до введения вырезок скрытых ошибок ~2,3 на страницу при одном чтении; в разделе Pignoria `both_wrong` ≈ 1,13 на страницу (три чтения, увеличенные кропы). Ripa 1603 сверяется с этими значениями после пилота (20 страниц): расхождений/страницу, `both_wrong`, `hidden_errors`, `[?]`, расход, страниц/час.
