# Задание разбирающему субагенту (одна страница, Alciato 1551)

1. Прочти `~/Projects/library/books/alciato/_text/ALGORITHM.md` целиком.
2. Картинка страницы: `_text/_img/NNNN.jpg` (NNNN — номер кадра, в задании). Вырезки по расхождениям: `_text/_work/NNNN/crops/NNNN_<id>.jpg` (по одной на расхождение тела). Список расхождений: `_text/_work/NNNN/diffs.json` (id, variants = три варианта read1/read2/read3, majority = индекс варианта большинства или null, ctx). Расхождения с `kind` field/marg/multi (поля, маргиналии) — решай по общему виду `_img`; при необходимости увеличь нужный участок фото через Python PIL — исходник `~/Projects/photos/alciato/frame_NNNN.jpg` (полное разрешение), результат сохраняй только во временную папку вне репозитория.
3. Не открывай `_reads/`, `emblems.json`, `entries.json`, `_translation/` — тексты уже в diffs.json; ты решаешь только по картинке.
4. По каждому `id` реши, кто прав, и запиши строку в `_text/_work/NNNN/answers.txt` ровно в формате (разделитель полей « ; »):
   ```
   N PAGES ; wrong=              (верен вариант большинства; ошибки нет — шум формата → пустой wrong)
   N READ2 ; wrong=1,3 ; hidden=text   (верен read2; ошибались read1 и read3; hidden — если два прочтения совпали на неверном: text|latin|margin; latin = греческий/иноязычное)
   N ERRATA:напечатано|исправление ; wrong=
   N FIX:точный верный текст ; wrong=1,2,3     (верного нет ни у одного)
   N UNSURE ; wrong=             (неразличимо → в тексте [?])
   N RECROP                      (вырезка промахнулась; пиши только если иначе нельзя)
   ```
   `wrong=` — номера прочтений, чей вариант НЕВЕРЕН по картинке (у варианта большинства — тоже, если он неверен). Ударения, тильды, æ/œ/ę, u/v/i/j — как напечатано. Опечатки печатника — только `ERRATA:`, если по вырезке однозначно (форма и то, что это опечатка); иначе как напечатано (PAGES/READn).
5. Затем просмотри всю страницу по `_img/NNNN.jpg` (и при сомнении — по увеличенному участку фото) на скрытые совпавшие ошибки (все три прочтения одинаково неверны, а в список не попали): ударения, тильды, æ/œ/ę, регистр, пропущенные слова, цифры, греческий, пунктуация в конце стихов. Найденное — строкой `NEW text|latin|margin ; было → стало` (`было` — точная уникальная подстрока текущего черновика `_text/pages/NNNN.md`, который ты МОЖЕШЬ прочитать для этой цели; `стало` — верный текст). Не правь ничего, в чём не уверен. Этот шаг ОБЯЗАТЕЛЕН для каждой страницы (даже если расхождений 0).
6. Строка NEW работает ТОЛЬКО по телу страницы. Исправления в строках `Колонтитул:`, `Кустод:`, `Сигнатура:`, `Маргиналии:` в NEW НЕ пиши; пиши их в `_text/_work/NNNN/footer_fixes.txt`, по одной строке: `было → стало`, и упомяни в ответе.
7. Ответ — только: «answers.txt записан, расхождений N, NEW M, страница просмотрена целиком» (+ footer_fixes, если есть). Без пересказа текста страницы.
