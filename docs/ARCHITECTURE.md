# Устройство библиотеки

Краткое техническое описание для ориентации в репозитории. Подробная история решений и нерешённых вопросов — в `HANDOFF.md` (может расходиться с `README.md` в деталях, где `README.md` не обновили после правки; в спорных местах доверять более новому `git log`).

## Где что лежит

- `index.html` — точка входа для GitHub Pages (`https://nfhours.github.io/library/`). Без `data-book` на блоке показывает список всех книг.
- `app.js` — вся логика: загрузка данных, маршрутизация по `location.hash`, рендер всех экранов (список книг, указатель книги, карточка статьи, просмотр таблиц). Один файл, без сборки и зависимостей, вставляется `<script src="app.js">`.
- `app.css` — всё оформление, через CSS-переменные на классе `.ic` (палитра/шрифты, единые для всех книг).
- `library.json` — реестр книг: `[{slug, path}]`. Добавление новой книги в указатель начинается отсюда.
- `motifs.json` — общий закрытый словарь мотивов (рог изобилия, змея и т.п.); статьи книг ссылаются на него по `id`, книги друг о друге не знают.
- `books/<slug>/book.json` — метаданные книги: заголовки/подзаголовки (ru/en/fr), автор, год, издатель, части (`parts`), и флаги поведения (см. ниже).
- `books/<slug>/entries.json` — статьи книги: `{items: [...]}`, один объект на статью/предмет.
- `books/<slug>/img/` — обработанные гравюры, по файлу на статью.
- `books/<slug>/pages/` — сканы страниц оригинала для раздела «Оригинал», подгружаются только при открытии раздела (ленивая загрузка).
- `books/<slug>/_work/` — рабочие файлы, вне репозитория (`.gitignore`).

## Как добавить книгу

1. Добавить запись `{slug, path}` в `library.json`.
2. Создать `books/<slug>/book.json` (title/subtitle на ru/en/fr, author, year, parts…) и `books/<slug>/entries.json` (`items`).
3. Положить гравюры в `books/<slug>/img/`, сканы страниц — в `books/<slug>/pages/`.
4. Дальше книга появляется в списке на `/` и открывается по адресу `#/<slug>` без правок `app.js` — вся логика (поиск, фильтры, сортировка, карточка статьи, «Оригинал») уже общая для всех книг.

Поведение книги настраивается ключами в `book.json`, а не кодом:
- `viewer:"plate"` — книга показывается как таблицы с номерами (Гроссон), а не как плоский список статей (Иконология).
- `sourceIsFrench` / `frIsTranslation` — откуда брать французский текст (оригинал или перевод).
- `flatGroups` — группы указателя не сворачиваются (`<details>`), показаны сразу раскрытыми.
- `showOriginal:false` — скрыть раздел «Оригинал».
- `favorites:true` — включает личное избранное (звёздочки, фильтр, экспорт списка) для этой книги; без этого флага книга работает как раньше, элементов избранного нет вообще.

## Маршруты (`location.hash`)

Разбор — `parseHash()` в `app.js`, диспетчеризация — `route()` (вызывается на `hashchange` и при первой загрузке).

| Адрес | Экран |
|---|---|
| `#/` или пусто | Список книг (если блок не закреплён `data-book`) |
| `#/<slug>` | Указатель книги |
| `#/<slug>/<id>` | Карточка статьи |
| `#/<slug>/about` | Страница «О книге» (если есть `book.meta.about`) |
| `#/<slug>/plate/<n>` | Таблица целиком с номерами (только `viewer:"plate"`) |
| `#/<slug>/fav=<id>,<id>,…` | Ссылка «Поделиться списком избранного» — предлагает добавить перечисленные id в избранное, затем заменяется на обычный `#/<slug>` |
| `#/p1-3` (без слага) | Старый формат до появления библиотеки — по-прежнему ведёт в `iconologie` |

Атрибут `data-book="<slug>"` на корневом блоке закрепляет его за одной книгой (адреса тогда без слага: `#/<id>` вместо `#/<slug>/<id>`); `data-book="library"` — особое значение, явно включающее список всех книг (так подключён `index.html`).

## Данные статьи (`entries.json` → `items[]`)

Ключевые поля (не все обязательны):
- `id`, `part`, `page`, `num` — идентификация и положение в книге.
- `fr`, `ru`, `en`, `name_fr` — название на разных языках.
- `group`, `group_fr`, `group_en`, `group_page` — заголовок раздела в указателе (буква/глава).
- `img` — файлы гравюры (`books/<slug>/img/`), `scans` — файлы скана страницы (`books/<slug>/pages/`) для «Оригинала».
- `text_fr`, `text_ru`, `text_en`, `text_frtrans` — тексты статьи (массивы абзацев); какой из них показан как «Перевод», а какой как «Оригинал», зависит от флагов книги `sourceIsFrench`/`frIsTranslation` (см. `textFor()` в `app.js` — там же подробный комментарий про эту развилку).
- `attrs` — список атрибутов изображения (`what`/`meaning` + переводы).
- `caption` — подпись на самой гравюре, если отличается от названия статьи.

Всё хранение данных — статические JSON-файлы, без бэкенда; единственное динамическое состояние на стороне посетителя — язык интерфейса (`localStorage`, ключ `ic-lang`), позиция в указателе за сессию (`sessionStorage`, ключ `ic-state:<slug>`) и, с появлением этой функции, личное избранное (`localStorage`, ключ `fav:<slug>` — JSON-массив id статей; см. `book.json` → `favorites`).
