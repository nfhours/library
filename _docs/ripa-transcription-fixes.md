## Поле `page`: правило

**page — номер страницы, на которой напечатан заголовок статьи (начало её собственного текста), одним числом, без диапазонов.** Вступление без заголовка с предыдущей страницы и лист гравюр в расчёт не идут. По этому правилу сверены все 440 записей по данным Грока; расхождений пять: p1-5 (→12), p1-123 (→187), p2-171 (→186), p2-256 (→253; Грок не отметил), p2-114 («141–145» → «141»; единственный диапазон в книге). Спорные у Грока p2-17, 52, 55, 59, 69, 78, 82, 88, 97 и p2-101 (page 123) соответствуют правилу — заголовок напечатан на указанной странице, **ложные**.
