# Рипа: недостающие страницы (сверка с Internet Archive)

Источник: https://archive.org/details/iconologieounouv00ripa — то же издание (Paris, Louis Billaine, 1677). Вёрстка проверена: с. 81 и 84 части 1 совпадают с нашими A080 и A081 строка в строку (строки, переносы, номера страниц).

## Метод
Все 548 листов Archive и все 512 наших страниц (`books/iconologie/pages/`) прогнаны через OCR (tesseract, eng), сопоставлены по словам и упорядочены динамическим программированием (порядок страниц сохраняется). У всех сопоставленных страниц сходство 0,5–0,95 (ниже — только листы с гравюрами и мало текста). Не нашлось пары у 39 листов Archive (нумерация листов — по Archive, с 1).

## Обрыв текста
Текст статей обрывался только на с. 82 (статья LIV «Exercice»: не хватало 3 абзацев — часы, золотой круг, свиток, чётки, половина крыла, орудия земледелия). Добавлено (text_fr, перевод RU/EN, attrs — 7 атрибутов вместо 2). Лист с гравюрами (26) текста не содержит.

## Происхождение в данных
`books/iconologie/book.json` → `source` перечисляет эти страницы и даёт ссылку. В `entries.json` верхнеуровневый ключ `ia_scans` — по каждому файлу `ia-*.webp`: часть, страница, лист Archive, источник, ссылка.
